## About Me

AI와 데이터 분야를 공부하면서 개발을 시작했고, 머신러닝·딥러닝·데이터 분석 프로젝트를 진행하며 다양한 문제를 해결해왔습니다.

프로젝트를 수행하면서 모델 자체보다 서비스가 실제로 운영되고 배포되는 과정에 더 큰 흥미를 느끼게 되었고, 자연스럽게 MLOps와 Kubernetes를 접하게 되었습니다.

현재는 인프라 엔지니어로 근무하며 Kubernetes 기반 환경을 중심으로 학습하고 있습니다.

새로운 기술을 배울 때 단순히 사용 방법만 익히기보다 왜 그렇게 동작하는지 이해하는 것을 중요하게 생각합니다.

특히 문제가 발생했을 때 증상만 확인하는 것이 아니라 원인을 추적하고 구조적으로 이해하는 과정에 흥미를 느끼고 있습니다.

최근 CKA(Certified Kubernetes Administrator)를 취득하였으며 Linux, Kubernetes, OpenStack, Ceph를 중심으로 학습하고 있습니다.
